# כללי שמות

- שם קובץ: English ASCII-friendly, Pascal/Kebab style לפי הדוגמאות הקיימות.
- כותרת בדף: עברית.
- בהופעה הראשונה: עברית ואחריה השם המקומי בסוגריים.
- `name_local` שומר את השם הגרמני/האוסטרי הרשמי.
- WikiLink מוצג בעברית באמצעות alias: `[[Maria-Theresa|מריה תרזה (Maria Theresia)]]`.
