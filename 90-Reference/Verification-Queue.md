# מידע שדורש אימות מחדש

לפני ביקור יש לבדוק מחדש:

- שעות פתיחה.
- מחירים.
- כרטיסים ושעות כניסה.
- תחבורה ציבורית ועבודות בקווים.
- שיפוצים וסגירות.
- תערוכות זמניות.
- מצב מסעדות ופתרונות כשרות.
- מזג אוויר בטיולי יום.
- נקודות עצירה מדויקות בטיולים המאורגנים.
